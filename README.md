# CCA 3 Computer Vision

This project contains computer vision experiments for image restoration, segmentation,
feature extraction, object detection, and motion analysis.

## Run
1. Install the dependencies with `pip install -r requirements.txt`.
2. Keep the notebook and `data` folder together.
3. Open `CCA3_Computer_Vision.ipynb` from this project folder in Jupyter.
4. Run **Kernel → Restart Kernel and Run All Cells**.

## Data
- `data/original_portrait.png` — first portrait
- `data/second_same_scene_photo.jpg` — supplied second photograph
- `data/original_video.mp4` — motion-analysis video
- `data/yolo11n.pt` — YOLO model (download separately; excluded from GitHub because it exceeds GitHub's 100 MB file limit)

Generated results are available in the `outputs` folder.
